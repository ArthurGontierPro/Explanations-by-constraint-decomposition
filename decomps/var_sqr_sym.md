# var_sqr_sym

Instance of `var_perm_sym` (`decomps/var_perm_sym.md`) specialised to a square matrix's row/
column/transpose symmetries — same `lex_lesseq`-per-generator shape, with the matrix's second
dimension addressed via the `R` index family already used by `lex2.md`/`table`, not a new
index family. Same G3 blocker, same E0/E2 hedge as `var_perm_sym`. No new file needed beyond
this pointer.
